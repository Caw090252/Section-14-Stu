# Texas CMV Section 14 Study App

This app is intentionally limited to **Section 14: Special Requirements for Texas Commercial Motor Vehicles** from the material provided for this study session.

## Included
- 63-question question bank
- Flashcards
- Topic filtering
- Randomized 10-question quizzes
- 25-question mock exam
- Explanations after answers
- Missed-question review
- Progress and accuracy tracking
- Local browser storage
- Mobile-friendly layout

## Put it on an iPhone as an app-like icon

1. Upload `index.html`, `manifest.json`, and `sw.js` to a static website host.
2. Open the resulting website in Safari on the iPhone.
3. Tap **Share**.
4. Tap **Add to Home Screen**.
5. Open it from the Home Screen.

GitHub Pages is a free option:
- Create a GitHub repository.
- Upload the three files.
- Open **Settings → Pages**.
- Choose **Deploy from a branch**, select `main` and `/root`, then save.
- Open the generated Pages address in Safari.

The app is a study aid, not an official Texas DPS application or test.
